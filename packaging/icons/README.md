# Иконки приложения

Сюда кладутся иконки, которые встраиваются в собранное приложение и установщик:

| Файл | Для чего |
|------|----------|
| `qlizmet.ico` | Windows: значок `.exe`, ярлыка и установщика |
| `qlizmet.icns` | macOS: значок в `.app` |
| `qlizmet.png` | Linux: значок в `.desktop` (рекомендуется 256×256) |

Сборка находит их сама: если файла нет, приложение соберётся со значком по
умолчанию — это не ошибка, а лишь повод не забыть про иконку.
