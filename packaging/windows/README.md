# Установщик для Windows

Собирается в два шага на машине с Windows.

## 1. Собрать приложение

```powershell
pip install -e ".[build]"
python packaging\build.py
```

Появится `dist\qlizmet` — папка с `qlizmet.exe` и всем необходимым.

## 2. Собрать установщик

Нужен [Inno Setup 6](https://jrsoftware.org/isdl.php). После установки:

```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" packaging\windows\qlizmet.iss
```

Готовый файл появится в `packaging\windows\output\qlizmet-<версия>-setup.exe`.

## Что делает установщик

- ставит приложение в папку пользователя — **права администратора не нужны**,
  а общих данных у приложения и нет: база лежит в `%APPDATA%\qlizmet`;
- предлагает создать ярлык на рабочем столе;
- предлагает включить запуск при входе в систему (по умолчанию **выключено** —
  включать автозапуск без спроса невежливо).

## Автозапуск и настройки приложения

Галочка в установщике пишет то же значение реестра, которым управляет сам
qlizmet в своих настройках:

```
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
    qlizmet = "C:\...\qlizmet.exe" --startup
```

Поэтому переключатель «Запускать при входе в систему» в приложении показывает
и меняет ровно то, что выставил установщик — они не спорят друг с другом.

Флаг `--startup` заставляет приложение стартовать сразу в трей, не открывая
окно: иначе qlizmet лез бы на экран при каждом включении компьютера.

## Удаление

Деинсталлятор убирает программу, ярлыки и запись автозапуска, но **не трогает
данные пользователя** в `%APPDATA%\qlizmet` — карточки и прогресс остаются.
Если нужно удалить и их, папку придётся стереть вручную.
